# Workday Spark

AI Workplace Productivity Assistant

Build a modern, responsive AI Workplace Productivity Assistant as a frontend-only SaaS-style web application.

Core Requirements

No backend

No login, registration, authentication, or user accounts

No database or server-side functionality

Keep the application simple enough to work within a free Lovable account

Use mock/sample AI responses where real AI functionality would require a backend

Focus on a polished, functional frontend experience

Main Features

1. Smart Email Generator

User enters an email topic or rough notes

Select a tone:

Formal

Friendly

Persuasive

Generate a professional email preview

Allow the generated email to be edited

Include actions such as Copy, Regenerate, and Clear

2. AI Research Assistant

User enters a topic, question, or article text

Generate a structured summary

Display:

Key points

Main insights

Recommendations

Make the generated content editable

Use sample/mock AI responses since there is no backend

3. AI Workplace Chatbot

Modern conversational chat interface

User can enter workplace-related prompts

Display realistic sample AI responses

Include suggested prompts such as:

"Help me write a meeting agenda"

"Summarise this information"

"Create a project plan"

"Improve this message"

UI & Design

Create a clean, modern, professional SaaS dashboard.

Light grey and dark colour palette

Minimal, sophisticated visual style

Responsive on desktop, tablet, and mobile

Left sidebar navigation

Dashboard home screen with feature cards

Clear typography and spacing

Modern buttons, cards, inputs, and text areas

Subtle hover and transition effects

Professional workplace aesthetic

Sidebar Navigation

Include:

Dashboard

Email Generator

Research Assistant

AI Chat

Settings

Settings can be a simple frontend page with basic interface options; no account or backend functionality is required.

Dashboard

The homepage should provide:

Welcome section

Short description of the assistant

Three main feature cards:

Smart Email Generator

AI Research Assistant

AI Workplace Chat

Quick-action buttons

Recent activity using static/sample data

Responsible AI

Include a visible but unobtrusive disclaimer:

"AI-generated content may contain errors or inaccuracies. Always review AI outputs before using them for important workplace decisions or communications."

Overall Goal

The final product should feel like a real, polished workplace productivity SaaS application, while remaining entirely frontend-only. Prioritize usability, visual quality, responsive design, and realistic interactions over complex functionality or backend integration.
